## 💡 HOW TO USE NEW COMPONENTS

Instead of writing verbose inline styles, use reusable components:

BEFORE (❌ Verbose):
  <div className="p-8 glass-panel rounded-3xl border border-white/10 hover:border-brand/40">
    <h3>{title}</h3>
    <p>{description}</p>
  </div>

AFTER (✅ Clean):
  import { ProjectCard } from './components';
  <ProjectCard title={title} description={description} tags={tags} />

Same with buttons:

BEFORE (❌ Verbose):
  <button className="bg-brand text-bg px-10 py-5 font-black rounded-lg hover:brightness-110">
    Click
  </button>

AFTER (✅ Clean):
  import { Button } from './components';
  <Button size="lg">Click</Button>
